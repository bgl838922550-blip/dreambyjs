# 金牌影院自定义媒体库

脚本：`jiabaide-mini-library.js`，版本 `1.2.0`，默认站点 <https://www.hxgnhb.cn/>。
已配置的其他站点地址会保留；旧 `jiabaide.cn` 地址沿用自动迁移规则。

## 首页

- 从官网首页接口实时读取轮播影片和横幅图片，按官网顺序展示，过滤广告。
- 轮播采用原图比例 `32:9`。在 App 的轮播比例设置中选择“跟随小程序”即可使用脚本比例。
- 分组为体育直播、正在热播、新片预告，以及官网频道顺序中的最新电影、电视剧、综艺、动漫和短剧。
- 正在热播支持分页；最新影视分组的“更多”进入对应完整片库，保留原分类筛选和排序。

## 体育

体育栏目包含官网当前直播与回放；“更多”可查看赛程并筛选足球、篮球。
打开赛事详情可选择 HLS 清晰度。播放时重新获取临时地址，并检查赛事身份，避免主播换场后播放另一场比赛。
未开播或已失效的赛事会显示状态；赛事回放按点播处理，支持进度与续播。

体育网站地址取自官网配置，体育页面使用桌面浏览器请求头，避免移动站跳转导致无法读取播放数据。
影视 Token、清晰度和选集流程继续使用原有接口。

## 验证

```sh
node scripts/test_jiabaide_mini_library_home.js
node scripts/test_jiabaide_mini_library_sports.js
```

首页测试同时运行原有影视播放回归。体育测试包含赛事身份、直播与回放区分、未开播状态、清晰度选择、临时地址刷新及公开入口调用。
